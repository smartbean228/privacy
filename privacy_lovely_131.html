二、信息收集与使用说明

本App属于离线工具类应用，绝大多数核心功能无需联网运行，不会收集任何个人敏感信息。为维持免费运营，应用可选择性展示第三方广告，详细说明如下：

1. 本App不会主动收集任何个人敏感信息，包括但不限于姓名、手机号码、身份证号码、通讯录、相册、麦克风、定位、本地文件等隐私内容。

2. 为正常展示广告、优化广告投放效果以及统计曝光数据，正规第三方广告SDK会读取设备基础匿名信息，包括ANDROID ID、设备型号、网络状态、匿名设备标识，所有数据无法定位真实自然人身份，仅用于广告展示、优化与数据统计。

3. App仅在加载广告时发起网络请求，日记记录、纪念日倒数、计算工具等核心功能全程离线运行，不会联网上传用户任何记录数据。

4. 第三方SDK所有数据处理行为均遵守各地隐私法规与应用平台规范，绝不会泄露、售卖用户相关数据。

三、本地数据存储

用户在App内创建的日记内容、纪念日数据、使用记录等全部资料，仅保存在用户本机设备当中，不会自动上传云端、同步服务器或者对外发送，用户可以随时手动清除本地数据。

四、第三方服务与信息共享

1. 本App仅接入各大应用商店审核认可的正规第三方广告服务商。

2. 不会向任何第三方转让、共享用户个人隐私数据。

3. 仅在司法机关、行政部门依法出具法定文书要求时，才会依规配合提供必要资料。

五、个性化广告与用户权益

App可能展示普通广告或者个性化推荐广告。用户可以在手机系统设置内关闭广告追踪与个性化推荐，关闭后不会影响App全部功能正常使用。

使用本App无需注册账号、登录账号。用户有权随时清理本地数据、关闭广告追踪、停止使用本应用。

用户同意本隐私政策后，应用才会启动广告服务并读取设备匿名信息；未同意前不会获取任何设备信息。

This app, "Love Diary Countdown", fully respects and protects the privacy of all users. This Privacy Policy clearly explains how the App collects, uses, stores, and handles information, as well as the rules regarding third‑party services. Please read it carefully before using the App.

1. This App does not actively collect any personal sensitive information, including but not limited to: name, phone number, ID number, contacts, photo album, microphone, location, local files, or any other private content.

2. To properly display ads, optimize ad delivery, and count impressions, certified third‑party advertising SDKs may read basic anonymous device information, including ANDROID ID, device model, network status, and anonymous device identifiers. All such data cannot be used to identify any real natural person; they are used solely for ad display, optimization, and statistical purposes.

3. The App initiates network requests only when loading ads. Core features — such as diary entries, anniversary countdowns, and calculation tools — run completely offline and never upload any user‑generated data to the internet.

All content created within the App — including diary entries, anniversary data, and usage records — is stored exclusively on the user's local device. It is not automatically uploaded to the cloud, synchronized to servers, or transmitted externally. Users may manually clear local data at any time.
